# Cognipeer

Cognipeer builds AI products and open-source building blocks for production AI: a gateway and control plane, agent runtimes, SDKs, UI components and document tooling.

## Start here

[**Cognipeer Console**](https://github.com/Cognipeer/console) is the self-hosted AI gateway and control plane. The other projects below either build on it or work well alongside it.
